# Stimuli

Audio assets for demonstration and testing of the MATLAB DAQ stimulus programs.

- `examples/` contains the two WAV stimuli supplied with the original archive and used by `stimulus_tools/playcue_choice.mlx`.
- Keep **actual experimental recordings, sensitive metadata, and large raw datasets** in an approved research data store instead of committing them here.
- Treat the provided WAV assets as **example stimuli, not acoustically calibrated reference standards**.

See [`examples/README.md`](examples/README.md) for the current filenames and compatibility notes.
